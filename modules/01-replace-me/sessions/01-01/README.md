# 01-01. Демонстрационная карточка

Эта карточка показывает минимальные файлы `README.md` и `rubric.md`. Автор заменяет
её до того, как курс увидит учащийся.

## Что должна содержать реальная карточка

Опишите одну идею, дайте достаточный контекст и два небольших примера или сценария.
Если порядок важен, добавьте timeline или data flow. Затем задайте одно упражнение,
которое можно закончить за 30–60 минут.

## Проверка

`pnpm session:check` выполняет локальные автоматические checks и не вызывает агента.
Если в manifest есть `review`, после зелёного check отдельный Codex-review сверяет
только README, DONE и rubric текущей карточки.

## DONE

- Демонстрационная карточка заменена реальной до публикации курса.
- У реальной карточки есть outcome, задание, checks и rubric.
