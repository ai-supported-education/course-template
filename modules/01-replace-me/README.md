# 01. Замените этот раздел

Это author-facing заполнитель. Перед публикацией курса замените его темой первого
раздела, обновите manifest и создайте реальные карточки в `sessions/`.

Не оставляйте этот module доступным учащемуся: он демонстрирует структуру, но не
является учебным материалом.
