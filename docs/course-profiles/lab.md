# Profile: lab

Используйте для практики, которая наблюдает или меняет состояние процесса,
устройства, сети, файловой системы либо внешнего сервиса.

## Safe-to-safe session

README обязан задать:

1. Явно разрешённую среду и targets; simulation/localhost предпочтительны.
2. Inventory и preflight инструментов, прав, свободного места, питания/связи и
   канала восстановления — только применимые пункты.
3. Baseline, сохраняемый до изменения.
4. Одно ограниченное и по возможности обратимое действие.
5. Stop conditions при неожиданном target, потере доступа, опасном состоянии или
   несоответствии baseline.
6. Raw evidence с командой/методом, временем и существенными параметрами среды.
7. Rerun policy: существующий raw artifact не перезаписывается молча; новая
   попытка получает отдельный run id/папку либо карточка останавливается.
8. Cleanup/rollback и post-check конечного состояния.

Expected output помечается до запуска; observed заполняется только фактическим
результатом учащегося. Evidence должен позволять восстановить порядок фаз: отметка
Expected создаётся до start marker первого действия, а raw output сохраняет время
и метод. Если реальная среда необязательна, предоставьте synthetic fixture и не
заявляйте, что он доказывает работу реального оборудования.

Agent review проверяет воспроизводимость evidence и соблюдение stop conditions. Он
не запускает рискованные действия повторно только ради подтверждения.
